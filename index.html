Utility Class Reference

Syntaxes for Tailwind in HTML

Category Class Prefix Description Code Example
Layout flex Aligns items in a row. <div class="flex gap-4">
grid Creates a grid system. <div class="grid grid-cols-2">
Spacing p-{n} Internal padding. <div class="p-8">
m-{n} External margin. <div class="m-auto">
Text text-{size} Changes font size. <h1 class="text-3xl">
font-{w} Changes font weight. <p class="font-bold">
Responsive md: Applies style on Desktop. <div class="w-full md:w-1/2">
Interaction hover: Style on mouse over. <button class="hover:bg-red-500">
